# Задание 1.1 - Калькулятор площади треугольника

Программа, которая вычисляет площадь треугольника по трём его
сторонам (по формуле Герона) с точность до сотых.

# Среда разработки

Язык программирования: Python.
Среда разработки: PyCharm 2026.2.1

# Инструкция по работе

По запросу программы ввести последовательно три стороны треугольника. Числа могут быть как целыми, так и дробными.

# Задание 1.2 - Конвертер единиц измерения расстояния

Программа-конвертер, которая переводит расстояние из одних единиц измерения в другие. Программа поддерживает следующие единицы: Километры (км), Метры (м), Сантиметры (см), Миллиметры (мм), Мили (mi), Ярды (yd).

# Среда разработки

Язык программирования: Python.
Среда разработки: PyCharm 2026.2.1

# Инструкция по работе

По запросу программы необходимо выбрать исходную единицу измерения, затем целевую единицу измерения, после чего ввести значение для конвертации. Единицы измерения выбираются из предложенного списка.
